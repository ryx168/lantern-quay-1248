# Guess the Stop · 猜猜這一站

A five-round GeoGuessr-style game on real XO Tours itinerary stops: look around a 360° view, drop a pin on the map, score by distance, and every reveal ends on the tour that stop belongs to.

Static page in `site/`, deployed to GitHub Pages by the workflow after a headless five-round smoke test (`scripts/smoke.mjs`). Phase 0 prototype: one fixed puzzle, no backend.
